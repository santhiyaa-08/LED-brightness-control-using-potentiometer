                      **LED Brightness Control Using Potentiometer**

**Objective**

To control the brightness of an LED by varying the resistance using a potentiometer.

**Components Required**

* LED – 1  
* Potentiometer – 1  
* Resistor – 1  
* Battery 9V – 1  
* Breadboard  
* Connecting wires

 **Simulation**
![simulation](simulation3-1.pdf)

Circuit simulation of LED brightness control using potentiometer.

 **Working Principle**

The battery provides power to the circuit. The potentiometer is used to vary the resistance in the circuit. When the potentiometer is rotated, the current through the LED changes, which changes the brightness of the LED.

**Result**
![result](Result.pdf)

The circuit was successfully simulated and implemented on a breadboard. The LED brightness changes when the potentiometer is adjusted.

 **Conclusion**

Thus, the LED brightness was successfully controlled using a potentiometer, demonstrating the basic principle of variable resistance and current control.
